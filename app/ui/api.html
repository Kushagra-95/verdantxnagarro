422 = invalid input. 404 = unknown job. 409 = stale proposal or conflicting state. 403 = cross-origin write.
Sign in at /login (or POST /api/auth/login with username/password). All data endpoints require a session cookie and an authorized environment_id query parameter or X-Environment-ID header. 401 = sign-in required; 403 = role denied; 404 = inaccessible workspace/resource.

GET /api/analysis/flexibility: hypothetical analysis with unchanged original baseline. GET /api/logs/{id}/evidence: full frozen evidence. Project filters: ?project=name on state, jobs, report, current export, logs and flexibility. Jobs accept project/team as legacy workload-group labels. Stable tenant_id/project_id/environment_id are assigned by the server. Use /admin for onboarding, membership, provider configuration and client reporting permission. GET /api/auth/me lists accessible workspaces. GET /api/organization/report requires platform administrator access and includes opted-in aggregates only.
